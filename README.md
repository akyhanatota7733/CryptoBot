## крипто бот для анализа крипто валют
мой давний проект, который был приватный, не знаю что там написано, но думаю от туда можно черпануть кода. Бот парсит сайт с ценами валют на основе их создает графики, которые он отправляет, так же при резких скачках цен он уведомляет об этом, могу еще добавить, что вроде как файл currency.txt в папке database это список всех валют, которые попадают под отслеживание 

crypto_bot.py - главный исполняемый файл

setting.ini - конфиг для данных по типу апи телеграм бота и прочее
