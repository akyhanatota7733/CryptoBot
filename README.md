## крипто бот для анализа крипто валют
мой давний проект, который был приватный, не знаю что там написано, но думаю от туда можно черпануть кода. crypto_bot.py - главный исполняемый файл

setting.ini - конфиг для данных по типу апи телеграм бота и прочее
